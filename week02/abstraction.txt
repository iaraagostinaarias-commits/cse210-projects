WHAT IS ABSTRACTION AND WHY IS IT IMPORTANT?

Abstraction is the way we can make complex things simpler, by breaking work down into smaller and more specific parts, each one with a clear purpose to be fufilled when needed. For example, in C# we have a class with its method that allows us to display messages in the screen to the user, this class is Console and on of its methosd is WriteLine() - Console.WriteLine(); -
The are many other classes that we can use from C#, but we can also create our own classes and tell them what we want them to do, we do so by creating variables or attributes, and methods or functions into the class. Each class need to be in their own .cs file, so that later we can call them in our main program when needed.
One of the benefits of creating classes is that in our main program we will write the core code that tells the program how to work in less lines of code, because we already wrote a block of code into each class, and we don't need to write all that code again to do something we need, we will just call the class and they will do their task.
Something importan about classes, is that we need to inicialize or instantiate them in our main code, that way we will have access to each variable and method into that class.

Here is an example of how Abstraction works:
        // In our main program, we called the method AddEntry from the Journal class to store the whole user entry (date, prompt, input) so that later if the user wants can store it into a file.
            newJournal.AddEntry(newEntry);

        // The previous snippet shows that we used a single line of code to call a method that performs its task; but, internally,
        this is what actually happens within the class (specifically in the block of code that involves the method we are calling)
            public List<Entry> _entries = new List<Entry>(); // A list variable
            public void AddEntry(Entry newEntry)
            {
                _entries.Add(newEntry); // We add the user entry/input to the _entries list to use it later in the program
            }

I think this is a very good example of how the principle of abstraction works because in just a few lines of code we were able to acomplish one of the main purposes of this program.
